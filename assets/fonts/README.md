# PDF fonts

Nanum Gothic Regular and Bold are bundled for searchable Korean PDF output.
They are loaded only when a PDF is generated and cached for the session.
jsPDF embeds only the glyphs used in each document.

Source: https://github.com/google/fonts/tree/main/ofl/nanumgothic
